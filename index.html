Dataset

Nidula Elgiriyewithana published the Credit Card Fraud Detection Dataset 2023 on Kaggle. It contains more than 550,000 anonymized transactions made by European cardholders in 2023.

Why this dataset?

The group sampled 600 rows because of the full dataset’s size. It gave the class a realistic binary classification task for comparing supervised learning methods.

FieldTypeMeaning
idIdentifierUnique ID of each transaction
V1–V28Anonymized featuresMasked transaction attributes
AmountNumericValue of the transaction
ClassBinary label1 = fraudulent, 0 = legitimate

Masking protects cardholders and limits what the group can say about real-world details such as transaction time, date, or location.

Methods and setup

Each model used 29 input features, with 480 rows for training and 120 for testing. The Perceptron used an entry-order split and had three more fraudulent transactions in its test set.

ModelTest setHow it worksReported settings
K-Nearest Neighbors (KNN)60 legitimate, 60 fraudFinds the five most similar labeled transactions and uses their majority label.k = 5, majority vote
Random Forest60 legitimate, 60 fraudCombines the predictions of multiple decision trees.Out-of-bag (OOB) score tracked
Perceptron57 legitimate, 63 fraudUses a linear decision boundary to predict one of two classes.Learning rate 0.01, bias 0, up to 100 epochs

How to read the scores

MetricFormulaQuestion it answers
Accuracy(TP + TN) / totalHow often was the model right overall?
PrecisionTP / (TP + FP)Of the fraud alerts, how many were correct?
RecallTP / (TP + FN)Of the actual frauds, how many were caught?
F1-score2PR / (P + R)How well did the model balance precision (P) and recall (R)?

TP means caught fraud, TN means correctly cleared legitimate transactions, FP means false alarms, and FN means missed fraud.

Limitations

The results describe how each model performed on this classroom sample.

  • Small sample

    Each model was evaluated on only 120 test transactions from the 600-row sample. One additional correct prediction changes accuracy by about 0.83 percentage points.

  • Different proportions in the test sets

    Perceptron tested on 63 frauds and 57 legitimate transactions. KNN and Random Forest each used 60 of each, so the precision and recall comparisons are less direct.

  • Anonymized features

    The masked V1–V28 fields make it difficult to explain model decisions in terms of real transaction details.

  • Real-world testing

    All three models need evaluation on more representative data before they are used on live transactions.
